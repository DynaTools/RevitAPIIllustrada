# Revit API Ilustrada em Python — códigos

Repositório público da **edição brasileira** do livro *Revit API Ilustrada em
Python — O método visual para a coordenação BIM e as aplicações MEP*, de
**Paulo Giavoni** (tradução de *Revit API Illustrata in Python*).

Na pasta [`codice/`](codice) está todo o código do livro, um arquivo por
bloco, com comentários e mensagens em português. No PDF, o selo
**</> Código P.C.n · copiar** embaixo de cada bloco leva direto ao arquivo
`codice/codice-P-C-n.py`. Leia o [README da pasta](codice/README.md) para
os detalhes.

- [`codice/`](codice) — o que o livro manda baixar: os scripts do
  RevitPythonShell, os grafos Dynamo (`.dyn`), as extensões pyRevit
  prontas para instalar (`.zip`), a planilha da WBS e as famílias-sonda.
- [`extensoes/`](extensoes) — as mesmas extensões pyRevit descompactadas,
  para ler o código aqui no GitHub sem baixar nada.
- [`NOMES-PT.md`](NOMES-PT.md) — os nomes que os scripts procuram ou gravam
  no modelo (parâmetros, worksets, botões). Se o seu modelo usa outros
  nomes, é a tabela para consultar.
